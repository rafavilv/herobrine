# Herobrine 67

Site de zoação e dossiê não oficial do Herobrine, com referências ao meme 67,
Cão Relha e Verity. A página também deixa cutucar o Herobrine. Os cards de memes
têm espaços reservados para imagens que devem ser adicionadas diretamente ao
HTML: coloque os arquivos em `images/` e substitua o conteúdo de cada
`.meme-image-slot` por uma tag `<img src="images/nome-da-imagem.jpg" alt="...">`.

Abra `index.html` no navegador para ver a página. O site é estático e não
precisa de instalação ou build.
